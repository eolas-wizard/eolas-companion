# Product Vision

## Purpose

Eolas Companion helps players spend less time researching and more time playing.

## Promise

**Play More. Research Less.**

Eolas should answer the player's next practical question quickly, preserve discovery, and reduce avoidable friction.

## What Eolas is

- A mobile-first game companion platform
- A personal progress and discovery record
- A decision-support tool that helps answer “What should I do next?”
- A reusable engine powered by game-specific Companion Packs

## What Eolas is not

- Another exhaustive wiki
- A cheat database
- A save editor
- A replacement for discovery or experimentation

## Reference implementation

Palworld is the first Companion Pack and the proving ground for shared platform systems. Features should improve Palworld while remaining reusable for future games whenever practical.
