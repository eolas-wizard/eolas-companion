# Decisions

## 2026-07-26 — Eolas is a platform

**Decision:** Rename the repository to `eolas-companion` and treat Palworld as the first Companion Pack.

**Reason:** Navigation, progress, accessibility, offline behavior, notebooks, and recommendations are reusable platform capabilities.

## 2026-07-26 — Separate versioning

**Decision:** Version the Eolas Platform independently from each Companion Pack.

**Reason:** Shared application changes and game-content updates will mature at different rates.

## 2026-07-26 — Preserve rather than restart

**Decision:** Refactor the working prototype instead of deleting it.

**Reason:** Existing work already validates core engine capabilities and includes real playtest feedback.

## 2026-07-26 — Alpha Notebook is the feedback source of truth

**Decision:** Contextual playtest observations should be recorded in the app and exported for sprint review.

**Reason:** This scales better than fragmented ad hoc feedback and can work across future Companion Packs.
