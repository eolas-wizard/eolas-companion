# Data Model

## Platform concepts

- Game
- Companion Pack
- Region
- Entity
- Objective
- Collectible
- Progress record
- Recommendation
- Notebook observation

## Palworld entity layers

### Reference

Identity, element, acquisition methods, work suitability, partner skill, drops, and practical notes.

### Progress

Seen, captured, capture count, fished, bred, Lucky, Alpha defeated, dungeon Alpha, and condensation progress.

### Optimization

Recommended roles, passive pros and cons, target passive combinations, breeding guidance, and condensation candidates.

## Dependency rule

A more advanced state may imply earlier states. For example, Captured implies Seen. Dependencies must be defined by each Companion Pack rather than hard-coded as universal assumptions.
