# Master Roadmap

## Platform Alpha 0.6 — Foundation transition

- Rename and reposition the project as Eolas Companion
- Separate shared engine files from Palworld data
- Establish platform and Companion Pack versioning
- Add project documentation and team ownership
- Preserve GitHub Pages deployment and Alpha 0.5 save migration

## Platform Alpha 0.7 — Progression model

- Captured automatically implies Seen
- Separate ownership, capture count, and special acquisition states
- Condensation and star-progress tracking
- Count-based regional collectibles such as Lifmunk Effigies and Mimogs
- Expand Alpha Notebook categories and export format

## Platform Alpha 0.8 — Player intelligence

- Today’s Adventure
- Next-best objective recommendations
- Region completion guidance
- Passive skill pros, cons, and role-based recommendations
- Condensation candidate guidance

## Platform Alpha 0.9 — Companion Pack framework

- Load games through manifests and standardized modules
- Add an Adventure selector
- Define import/export boundaries per game
- Create a starter template for new Companion Packs

## Platform 1.0

- Stable mobile-first navigation and accessibility
- Reliable offline behavior and progress backup
- Mature Palworld Companion Pack
- Documented process for adding another supported game

## Candidate Companion Packs

- Cell to Singularity
- Dune: Awakening
- Stardew Valley
- Harvestella
- V Rising

Candidates are not release commitments. Each requires a discovery brief and data-source review before scheduling.
